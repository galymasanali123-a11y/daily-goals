# Hangul primer and eight dialogues (A1 → B2)

This is an original hangul primer plus eight original dialogues. It is not a scan of a commercial Korean textbook.

**FSI source we analyse (not reprint).** *Korean Basic Course* (Foreign Service Institute, United States government). US federal works of that type are generally in the **public domain**. We do **not** copy FSI drill pages. We keep a few **topic** ideas (shop, transport, health, work) and rewrite them in **2010s–2020s 해요체**.

**Licence of this file.** Original course text.

---

## What this book is

Hangul is a featural alphabet written in syllable blocks. If you only romanise, you never see Korean. This file forces blocks, then puts them in dialogues from café-simple to workplace-polite.

---

## Honest analysis of FSI Korean Basic Course

**Strengths**

- **Drills.** Substitution and transformation drills build automatic endings. Modern apps often skip this and hope “immersion” will glue 요 on for you.
- **Topic spine.** Shop, directions, food, office — still the right adult topics.
- **Public domain.** You may legally read FSI. That matters in a world of scanned paywalled PDFs.

**Limits (why we do not clone it)**

- **Dated register.** Mid-century course Korean leans on stiff honorifics, older vocabulary, and classroom English that sounds like 1960s Washington. Some dialogues feel like embassy hallways, not a Seoul subway in 2024.
- **Romanisation-heavy habits.** Learners hide in McCune–Reischauer or whatever the edition used. We write 한글 first.
- **Gender and social assumptions.** Treat them as historical. Do not copy who gets to speak how.
- **We keep 해요체 as the default polite spoken style** for this app: *주세요, 어디예요, 괜찮아요.* We introduce 하십시오체 as a recognition layer (announcements, forms), not as your first mouth.

**How we use FSI**

Topic spine only. If you open FSI, use it as extra drill after you can read our blocks. Do not mix 1960s 하십시오체 into a convenience-store chat unless the clerk is a robot from a training film.

## Study method

1. Copy each block by hand once.  
2. Highlight the particle (은/는, 이/가, 을/를, 에, 에서).  
3. Cards: Korean on front, your language on back, example from the dialogue.  
4. Say the dialogue. 해요체 should feel like a default coat, not a costume.

## Syllable-block practice

Korean letters group into squares: 초성 (initial) + 중성 (vowel) + optional 종성 (batchim).

**Six vowels to write today**

- 아 에 이 오 우 으  
  Words: 아이, 네, 이사, 오리, 우리, 음식  

**Six consonants in initial position**

- ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ  
  가 나 다 라 마 바  

**Batchim that change your life**

| Block | Sound note | Example |
| --- | --- | --- |
| ㄱ/ㅋ/ㄲ as 받침 | often [k̚] | 부엌, 먹다 |
| ㄴ | [n] | 한국 |
| ㅁ | [m] | 이름 |
| ㅇ as 받침 | [ŋ] | 방 |
| ㄹ | [l]~[ɭ] | 서울 |
| ㅂ | [p̚] | 밥 |

**Minimal pairs (read aloud)**

- 불 / 풀 / 뿔  
- 갈 / 칼 / 깔  
- 방 / 발 / 밤  

**A line to copy (no romanisation on the card)**

안녕하세요. 저는 학생이에요. 한국어를 공부해요.

If you cannot copy that from memory after two days, stay on blocks. Dialogues will not save you.

## Particles in one box

- 은/는 — topic  
- 이/가 — subject (often new or focused)  
- 을/를 — object  
- 에 — time / destination  
- 에서 — place of action  
- 하고 / 와 — and / with  
- 도 — also  
- 만 — only

## Eight original dialogues

### 1. Store (A1) — 편의점

점원: 안녕하세요.  
손님: 안녕하세요. 물 하나 주세요.  
점원: 네, 여기요. 천 원이에요.  
손님: 가방은 어디에 있어요?  
점원: 저기, 과자 옆에 있어요.  
손님: 감사합니다.

**Chunks:** 주세요, 여기요, 어디에 있어요, 옆에

---

### 2. Subway (A2) — 지하철

A: 이 열차 시청 가요?  
B: 아니요. 다음 거 타세요. 이번 건 급행 아니에요.  
A: 몇 번 출구예요?  
B: 3번 출구요. 계단 많아요. 엘리베이터는 오른쪽에 있어요.  
A: 카드 어디에 찍어요?  
B: 개찰구에서 찍어요.

**Chunks:** 다음 거, 급행, 출구, 찍어요

---

### 3. Clinic reception (A2) — 병원 접수

직원: 성함이 어떻게 되세요?  
환자: 김민수예요.  
직원: 어디가 불편하세요?  
환자: 어제부터 목이 아파요. 열은 없는 것 같아요.  
직원: 진료는 10분 뒤에 시작해요. 저쪽에 앉아 주세요.  
환자: 보험 카드 보여 드리면 돼요?  
직원: 네, 주세요.

This is language class, not a diagnosis. Real illness: a real clinician.

---

### 4. Clinic room (B1) — 의사와 환자

의사: 언제부터 그러셨어요?  
환자: 삼일 됐어요. 기침이 나와요. 숨은 괜찮아요.  
의사: 가래는요?  
환자: 조금요. 색깔은 투명해요.  
의사: 지금은 검사 이야기만 할게요. 약은 진찰 후에 병원에서 정해요. 앱에서 따라 하지 마세요.  
환자: 네. 다시 말하면, 오늘은 증상만 말하고 결정은 선생님이 하시는 거죠?  
의사: 맞아요.

**Teach-back** is in the last two lines. Keep it.

---

### 5. Work (B1) — 사무실

팀장: 회의 자료, 오전까지 가능해요?  
민지: 차트는 돼요. 번역은 오후 두 시요.  
팀장: 그럼 두 시까지 채팅으로 보내 주세요. 오늘은 짧게 갑시다.  
민지: 알겠습니다. 아, 해요체로 해도 될까요? 고객 메일은 존댓말 길게 쓸게요.  
팀장: 우리끼리는 해요체 괜찮아요.

Register shift: 하십시오체 *알겠습니다* to a manager, then negotiate 해요체 in-team. That is 2010s office, not FSI embassy.

---

### 6. Store complaint (B1–B2)

손님: 이거 어제 샀는데요, 전원이 안 켜져요.  
점원: 영수증 있으세요?  
손님: 문자로요. 교환 되죠?  
점원: 박스 있으면 오늘 교환 가능해요. 기스는 책임 못 져요.  
손님: 기스 없어요. 확인해 주세요.

**Chunks:** ~는데요, 되죠?, 책임 못 져요

---

### 7. Subway delay (B2) — 안내와 짜증

방송: 고객 여러분, 신호 점검으로 열차가 지연됩니다. 불편을 드려 죄송합니다.  
승객1: 몇 분이에요?  
승객2: 안 알려 주네요. 택시는 더 막혀요.  
승객1: 회사에 늦는다고 보낼게요.  
승객2: 해요체로요? 팀장이면 조금 더 공손하게.  
승객1: “도착이 늦을 것 같습니다.” 이 정도면요.  
승객2: 그거 괜찮아요.

Recognition of 하십시오체 in the announcement vs spoken plan.

---

### 8. Work opinion (B2) — 도시와 출퇴근

A: 서울은 편리한데 전셋값이 너무 세요.  
B: 세다고요? 저는 출퇴근 한 시간이 더 힘들어요.  
A: 재택이 늘어나면 교반도 살 만하죠.  
B: 팀 성격 따라 다르지 않아요? 우리 팀은 아직 대면 회의가 많아요.  
A: 그래서 나는 “무조건 서울”은 아닌 것 같아요.  
B: 그 말, 지난 회의에서 좀 더 부드럽게 했으면 좋겠어요. “아닌 것 같아요”가 나아요. “말도 안 돼요”는 너무 세고요.

Opinion + meta-pragmatics: how strong the sentence sounds. That is B2.

## Batchim practice page (copy by hand)

Write each line twice. Cover the right column.

| Write | Then say (hint) |
| --- | --- |
| 한국 사람 | 한국 |
| 이름이 뭐예요? | 이름 |
| 점심을 먹어요 | 밥 계열 |
| 책을 읽어요 | ㄺ → 흔히 [일꼬] 쪽으로 익히기 |
| 옷을 입어요 | 받침 ㅅ |
| 앞에 앉아요 | 앉 |
| 값을 깎아 주세요 | 값, 깎 |
| 없어요 / 있습니다 | 없, 습 |

**Liaison (연음) four lines**

- 옷이 → 오시  
- 옷을 → 오슬  
- 읽어요 → 일거요에 가깝게  
- 좋아요 → 조아요  

If your teacher uses a different phonetic spelling, follow the teacher. The point is: the block is not the same as the sound.

## 해요체 vs 하십시오체 vs 반말 (when)

| Style | Where in this file | Mouth default? |
| --- | --- | --- |
| 해요체 | Dialogues 1–6, 8 | Yes, for the course |
| 하십시오체 | Subway announcement, email flavour, *알겠습니다* | Recognition + rare work |
| 반말 | Not drilled here | Only with real agreement in real life |

FSI often marches you through formal endings early because diplomats needed them. You are not a 1960s attaché. Learn to *hear* 하십시오체 in 안내 방송, then answer your friend in 해요체.

## Extra A1 substitution drill (original, FSI-shaped but new words)

Pattern: 이거 주세요.  
Swap: 물 / 커피 / 가방 / 영수증 / 휴지  

Pattern: 어디 있어요?  
Swap: 화장실 / 출구 / 엘리베이터 / 약국  

Pattern: 얼마예요?  
Answer frames: 천 원이에요 / 오천 원이에요 / 카드 되요? → **돼요**

Say each set in 30 seconds. That is the FSI inheritance: speed of endings. The lexicon is ours.

## Culture notes without a textbook lecture

- 성함 is honorific for “name” at the clinic. 이름 is fine with friends.  
- 어디가 불편하세요? is softer than a blunt 뭐가 아파요? in some clinics. Both exist.  
- 드림 / 올림 close emails; 해요체 Slack is a different country on the same phone.
